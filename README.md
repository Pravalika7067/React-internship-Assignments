# React Internship Assignments

A collection of React.js internship assignments built to strengthen core concepts of modern frontend development including components, props, state management, hooks, and UI composition.

[React Internship Assignments Repo](https://github.com/Pravalika7067/React-internship-Assignments?utm_source=chatgpt.com)

---

## 📌 Overview

This repository contains multiple React-based assignments completed as part of an internship training program. Each assignment focuses on a specific React concept, gradually progressing from basic component structure to more advanced state-driven UI development.

The goal of this project is to build strong fundamentals in React by implementing real-world UI patterns and component-based architecture.

---

## 🚀 Key Learning Outcomes

* Understanding React component-based architecture
* Working with JSX syntax and rendering logic
* Passing data using **props**
* Managing state using **useState hook**
* Handling user interactions (events)
* Rendering dynamic lists using `.map()`
* Component reusability and composition
* Basic UI structuring and styling

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Pravalika7067/React-internship-Assignments.git
```

Navigate into the project:

```bash
cd React-internship-Assignments
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
